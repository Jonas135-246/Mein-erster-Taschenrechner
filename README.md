# Mein erster Taschenrechner

Ein konsolenbasierter Taschenrechner in Java, der Benutzereingaben verarbeitet und mathematische Grundoperationen ausführt. Dies ist mein allererstes eigenständiges Programmierprojekt.

### Funktionen
- **Grundrechenarten:** Plus (`+`), Minus (`-`), Mal (`*`) und Geteilt (`/`).
- **Fehler-Validierung:** Das Programm fängt das Teilen durch Null (`0`) ab und gibt eine eigene Fehlermeldung aus, statt abzustürzen.
- **Interaktivität:** Zahlen und Rechenzeichen werden live über die Konsole eingetippt.

### Gelernte Grundlagen
- Benutzereingaben mit der Klasse `Scanner` verarbeiten
- Kontrollstrukturen (`if`, `else if`) für die Rechenlogik
- Datentypen wie `double` (für Kommazahlen) und `char` (für Symbole)
- Vorzeitiger Programmabbruch mit `return` bei Fehlern
